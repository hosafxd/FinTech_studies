# S&P 500 (SPX) Historical Returns

> **Category:** Market Data  
> **Source CSV:** `spx_returns.csv`

## Description

Time-series of S&P 500 index returns used as the diversified-portfolio benchmark across the notebooks (portfolio optimization, time-series analysis, regime detection).

## When this dataset is useful

- Benchmark series for portfolio-optimization examples
- Time-series / GARCH demonstrations on a low-noise broad index
- Comparing single-name (NVDA) vs index (SPX) volatility and drift behavior
- Backtesting baseline (1/N, buy-and-hold) comparisons
